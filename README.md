# After Hours Fleet Desk

Private source repository for the fleet-support portfolio and daily FMCSA outreach automation.

- `website/`: complete 3D website, both deployment editions, local preview server, vendored libraries, fonts, and verification scripts.
- `automation/`: Google Apps Script source and manifest, with setup and maintenance notes.
- `repeset/`: archived project notes, outreach records, screenshots, earlier versions, original exports, and restoration checksums.

The website and automation run separately. Saving code here does not change the hosted website, Apps Script project, triggers, or Gmail account.

The working source folders contain the website and daily automation. Historical prospect records, mailbox screenshots, private notes, and original exports are preserved in labeled archives under `repeset/`, as requested by the owner. Credentials, OAuth tokens, and live Script Properties are excluded. Third-party asset licenses are retained.

See each folder's README for running and restoring the project.
