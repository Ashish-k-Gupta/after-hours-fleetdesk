# Archived local project records

This folder preserves the additional local records requested by the repository owner on 2 November 2026. The folder name `repeset` follows that request.

The working project remains in the repository's `website/` and `automation/` folders. These archives preserve historical records and original paths; extract only the archive you need into a separate folder.

| File | Contents |
| --- | --- |
| `notes.zip` | Original README history, CHECKPOINT decisions and continuation context, design QA, and scenery measurements (4 files). |
| `outreach.zip` | Five-carrier research, published contacts, personalized message text, sending timestamps/receipts, and a Sent Mail screenshot (4 files). |
| `screenshots-references.zip` | 45 project screenshots and 2 design references (47 files). |
| `website-history.zip` | Six experiment backup folders and eight older deployment ZIPs (85 files). |
| `automation-history.zip` | Original Code.gs export with the historic ten-recipient manual batch, previous GitHub verification JSON/ZIP, and the three registration-filter troubleshooting files (6 files). |
| `previous-upload.zip` | Complete earlier website-only GitHub upload package (74 files). |
| `initial-checkpoint.zip` | Original 24 October project checkpoint, retained unchanged (33 files). Its original checksum is in `initial-checkpoint.sha256`. |
| `manifest.json` | Original locations, archive descriptions, file counts, SHA-256 checksums, and per-entry checksums for the newly created ZIPs. |

Together, these archives preserve all 140 local-only files from the original `otr-route-atlas` folder. Its other 72 website/code files already exist unchanged in `website/`. The earlier upload package and named output records are preserved as well.

The archives include business contact records, mailbox screenshots, private development context, and superseded code. The repository is private. Historical instructions describe earlier states; use current user instructions and the working source when continuing development. The original manual sending function is kept for historical reference; the active `automation/Code.gs` retains its disabled placeholder for that old batch.

Gmail messages, live Apps Script triggers, Script Properties/contact ledger, and hosting configuration remain in their external accounts. Saving these records to GitHub does not migrate or run them. No local originals were removed during this backup.
